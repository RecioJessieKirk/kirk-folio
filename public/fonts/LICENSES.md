# Local font sources

Fonts were copied from the user-supplied local Proxima Nova and Switzer_Complete folders on 2026-10-27. No conversion or subsetting was performed.

- Proxima Nova: regular, semibold, and bold desktop OTF files; used for headings. Supplied license preserved in [licenses/proxima-nova.txt](licenses/proxima-nova.txt).
- Switzer: supplied variable WOFF2, used for body text, technology labels, and project tags. Supplied Fontshare license preserved in [licenses/switzer.txt](licenses/switzer.txt).

Before public launch, confirm the correct Proxima Nova webfont rights and files. The supplied generic Fontspring license refers to Eurocine and distinguishes webfonts from full desktop CFF/TrueType files; it does not establish permission to serve these Proxima desktop OTFs. Current local integration is not a licensing verification. Replace the files/face declarations with the correctly licensed webfont files when confirmed.
